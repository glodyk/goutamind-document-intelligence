# Golden example (synthetic)

`synthetic_claim_bundle.pdf` is an invented 16-page claim bundle generated by
`python -m scripts.make_synthetic_bundle` from
`tests/fixtures/synthetic_bundle.py`. No real person, facility or claim is in
it.

It covers the structural cases seen in real bundles (DATA_MODEL 48): several
logical documents in one PDF, an untitled SEP page, printed page counters,
blank separator pages, an image-only page, two lab reports in a row, an
ambiguous numeric date, a month-precision date, a "-" value, and a medical
device on a prescription line.

| File | Content |
|---|---|
| `synthetic_claim_bundle.pdf` | the input |
| `synthetic_claim_bundle.inspection.txt` | human-readable result: pages, documents, evidence, facts, events |
| `synthetic_claim_bundle.bundle.json` | the full output of every layer |

`tests/integration/test_vertical_slice.py::test_golden_example_is_up_to_date`
fails when the pipeline's output changes, so behaviour changes are always
visible in review. Regenerate the files when a change is intended.

The example currently covers PDF -> classification -> documents -> evidence ->
minimal facts/events. Canonical claim, timeline, narrative and intelligence
will be added as those layers are built (Project Instructions section 27).
